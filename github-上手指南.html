第一次把代码放上 GitHub

照着做,全程大概 40 分钟。做完你会有一个自己的仓库,网址是 github.com/你的用户名/my-first-page。

练手项目已备好:C:\Users\luoha\Desktop\my-first-page
1

确认 Git 装好了

1 分钟

Git 是装在电脑上的工具,GitHub 是网站。先要有工具,才谈得上传东西。

按 Win + X,选「终端」或「Windows PowerShell」,把这行敲进去:

git --version
成了的样子:出来一行 git version 2.5x.x 之类的版本号。
如果提示找不到 git:说明还没装好,或者装完没重启终端。关掉窗口重开一次再试;还不行就告诉我。
2

注册 GitHub 账号

6 分钟

账号免费。注册好之后,你就有了一个全球公开的"门牌号"。

  1. 打开 github.com,点右上角 Sign up
  2. 填邮箱、密码、用户名
  3. 邮箱里会收到验证码,填进去
用户名想清楚再填——它会变成你的网址,以后能改但很麻烦,而且别人可能抢注。建议拼音加数字,比如 luohailong-dev。别用中文,别用奇怪符号。
给同学看的时候:GitHub 上的一切默认是公开的,任何人都能搜到你。用户名建议不要用学号。
3

在网站上建一个空仓库

3 分钟

"仓库"就是项目文件夹的网上版本。我们先建个空的,一会儿从电脑里推上去。

  1. 点上方的 + → New repository
  2. Repository name 填 my-first-page(必须和本地文件夹同名)
  3. 选 Public
  4. 下面那几个勾——README、.gitignore、License 全部不要勾
  5. 点绿色的 Create repository
这一步最容易出事:如果勾了「Add a README」,GitHub 会先给你造一个文件,后面推送就会打架报错。保持全空,页面上会显示一段命令提示,先别关这个页面。
4

把本地文件夹推上去

8 分钟

这是核心动作。五条命令,一条一条来,别一次全粘进去。

先进入项目文件夹(注意路径里的 \ 不要改):

cd C:\Users\luoha\Desktop\my-first-page

把这个文件夹变成 Git 仓库:

git init

告诉 Git 你是谁(只做一次,以后不用再做):

# 把双引号里的内容换成你自己的
git config --global user.name "你的名字"
git config --global user.email "你的邮箱@example.com"

把这三个文件记下来,保存一次版本:

git add .
git commit -m "第一次提交:我的第一个网页"

告诉本地仓库"网上那个在哪":

# 把 YOUR-USERNAME 换成你的 GitHub 用户名
git remote add origin https://github.com/YOUR-USERNAME/my-first-page.git
git branch -M main

推上去:

git push -u origin main
关键一步:执行 push 之后会弹出一个窗口写着「Connect to GitHub」。点 Sign in with your browser,浏览器里登录 GitHub,点绿色的 Authorize。授权完回到终端,进度条走完就成了。
不用去折腾那串又长又难的 token。Windows 上的 Git 自带凭据管理器,会自动帮你登录并把凭证存好,以后不用再输。网上很多老教程还在教手动做 token,不用管。
5

验证一下,然后学会日常循环

4 分钟

跑通一次不算会,能重复才算。

刷新刚才那个 GitHub 页面,三个文件应该都躺在上面了。点开 index.html 还能直接看到源码。

以后每次改完代码,只要三行:

git add .
git commit -m "这次改了什么,一句话写清楚"
git push

改一次推一次,你的每一次改动 GitHub 都替你留着,想退回哪一版都行——这就是它比"新建副本2"强的地方。

卡住了怎么办

无法将"git"项识别为… Git 没装好,或者终端是装之前开的。关掉重开。
remote origin already exists 之前加过了。敲 git remote set-url origin 你的网址 覆盖掉。
Authentication failed 授权窗口被你关掉了,或者登错了账号。重跑一次 push,选浏览器登录。
failed to push some refs / rejected 远程有本地没有的东西(多半是建仓库时勾了 README)。先 git pull --rebase origin main,再 push。
Connection timed out 网络到 GitHub 不通,换个时间或换网络再试。这是网络问题,不是你的操作问题。
fatal: not a git repository 没进到项目文件夹里,或者忘了 git init。敲 cd 回到 my-first-page 再看。
Author identity unknown 第 4 阶段的 git config 那两行没配。补上再 commit。

公开仓库里,什么能放什么不能放

可以放

  • 练习代码、课程项目
  • 学习笔记、思路整理
  • 公开课作业

绝对别放

  • 学号、身份证、手机号
  • 宿舍楼栋、家庭住址
  • 密码、密钥、任何 token
  • 医院的真实病人资料
  • 实习单位的内部文件

最后一条对你要格外留意:护理专业以后接触的都是真实病案数据。 这些数据一次都不能出现在公开仓库里,这是法律问题,不是习惯问题。
