Git 速查卡

罗四维专用 · 放在 my-first-page 里 · 手机也能开
唯一要刻在脑子里的习惯：改之前先 commit。
存档多的人不怕改坏；存档少的人改一次怕一次。

三个判断（记住这三个问题就够了）

日常我刚改完，要保存
git add .
git commit -m "这里写改了什么"
git push
add 只挑出来，commit 才存档，push 才上传。三步各干各的。
救命我把文件改坏了，想变回上次保存的样子
git restore 文件名
例：git restore index.html。把 .git 里最近一次存档复制回来覆盖硬盘上的坏文件。存档不动，安全。
穿越我想看很久以前某一版长什么样
git restore --source=编号 文件名
编号不用背，从下面 git log 里抄。看完想回来，再敲一次不带 --source 的 git restore 文件名。

两条随时要敲的

查状态我现在是什么情况？下一步干嘛？
git status
git 不只报问题，还会在括号里告诉你解决办法。迷路了先敲它。
查存档我有哪些存档？编号是多少？
git log --oneline
每一行开头那 7 位就是存档编号。按 q 退出。

踩过的坑，别再踩：

1. 输入法是中文状态时，终端里会打出 ·，导致命令报错——敲命令前先按 Shift 切英文，或鼠标右键粘贴。

2. wc、ls、cat 是 Linux 命令，PowerShell 里没有。看文件大小用 dir 文件名 或 (Get-Item 文件名).Length。

3. 浏览器地址栏是 file:// 开头 = 本地文件；https:// 开头 = 线上网站。本地改完不 push，线上不会变。

4. push 后 GitHub Pages 要等 1-2 分钟才更新，404 不一定是失败。
