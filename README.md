# my-first-page

我的第一个 GitHub 仓库。一开始用来练 Git，现在也放我给自己做的小工具。

## 文件目录（一眼看懂版）

| 文件 | 是什么 |
|---|---|
| `index.html` | 网站首页 / 自我介绍。**名字不能改**，GitHub Pages 认准它当入口 |
| `drip.html` | 输液滴速计算器：填液体总量、时间、滴系数，算出每分钟滴数，带快慢提示 |
| `imaging.html` | 医学影像检查速查卡：X线 / CT / MRI / 超声 / 血管造影，点卡片展开 |
| `xiangqi.html` | 中国象棋：可悔棋、摆棋沙盘、人机对弈（简单/普通/困难）、将军特效 |
| `git-cheatsheet.html` | Git 速查卡：三条判断 + 两条查询 + 踩坑记录 |
| `github-上手指南.html` | 当初带我入门 Git 的五阶段操作指南，含报错对照表 |
| `README.md` | 本文件，仓库说明书 |

## 我在练什么

- Git 日常三连：`git add` → `git commit` → `git push`
- 回档：`git restore`（回到最近存档）、`git restore --source=编号`（回到指定存档）
- 用 HTML + CSS + JavaScript 从零写页面，不靠框架
